# Cozy Corner ✦ Intimate Atmospheric Ambient Sanctuary

A warm, romantic study & relaxation space with pixel-aligned video backdrops, visual weather physics, customizable lamp lighting, procedural ambient soundscapes, and full official studio music discographies.

---

## ✨ Features

- **Cozy Dual Rooms**: Seamlessly switch between **Cozy Haven** (Girl Room) and **Loft Studio** (Boy Room).
- **Official Studio Music Discographies**:
  - **The Weeknd**: 18 tracks ranked from most popular (*Blinding Lights*, *Starboy*, *The Hills*, *Save Your Tears*, etc.).
  - **One Direction**: 17 tracks ranked from most popular (*What Makes You Beautiful*, *Story of My Life*, *Night Changes*, *Drag Me Down*, etc.).
  - **Linkin Park**: Complete official studio hits (*Numb*, *In The End*, *Somewhere I Belong*, *Faint*, *Lost*, etc.).
  - **Metallica**: Complete studio hits (*Nothing Else Matters*, *The Unforgiven*, *Fade To Black*, *Master of Puppets*, etc.).
  - **Soft Lo-Fi**: 24/7 study beats & relaxing melodies.
  - **Custom Stream Support**: Paste any YouTube link, playlist, or direct MP3 audio stream URL.
- **1-Click Quick Controls**:
  - **1-Click Playlist Switcher**: Instantly cycle playlists and matching aesthetic color themes with one click.
  - **1-Click Ambient Sound Cycler**: Cycle between procedural Rain, Calming White Noise, Analog Lo-Fi Vinyl Crackle, or Layered Harmony.
  - **1-Click Lamp Lighting**: Amber, Rose Quartz, Cyber Cyan, Moonlight, Candle Flame.
  - **1-Click Window Weather**: Rain, Storm & Lightning, Snow, Firefly Motes, Fog, and Clear.
- **Study Focus Timer**: Integrated 25-minute Pomodoro focus countdown with gentle audio chime.
- **Wholesome Fullscreen Mode**: Hide all UI elements for distraction-free focus.

---

## 🚀 How to Run the Project

### Method 1: Using NPM (Recommended)
```bash
npm start
# or
npm run dev
```
Then open [http://localhost:3000](http://localhost:3000) in your browser.

---

### Method 2: Using Python
```bash
python -m http.server 8080
```
Then open [http://localhost:8080](http://localhost:8080) in your browser.

---

### Method 3: Direct Open
Double-click `index.html` to open directly in any modern web browser!
